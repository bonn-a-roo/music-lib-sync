# UI and authentication guidance

- `ui/uimanager.py`: MainWindow handles account selection/background authentication; SyncWindow handles songs, playlists, repair, progress/ETA, cancellation and bounded logs; OptionsWindow edits destination, cookies and audio format. AuthWorker and generic SyncWorker catch exceptions before they escape QThread.run. Manual OAuth URL dialogs stay on the GUI thread.
- `ui/library_browser.py`: authenticated library browser with immutable snapshot model/view, search/presence filtering and cancellable background metadata/scanning worker. Browsing remains read-only; selected-collection/track sync, retry, a single-active queued mutation controller, stable-ID WorkerEvents and cancel/close handling are integrated. Previous rows remain visibly stale on refresh errors. The browser queue also runs confirmed whole-library Repair Library and Sync all; existing SyncWindow remains available for batch paths during validation. Repair progress/results are aggregate, followed by filesystem rescan. `ui/playback.py` supplies persistent local controls/queue and async FFmpeg fallback for Qt codec gaps; Computer Use/audible-output validation remains pending.
- `model/user.py`: validates/refreshes cached tokens, performs state-checked loopback OAuth, and caches the authenticated profile. Getters do not call Spotify. Required scopes: `user-library-read playlist-read-private playlist-read-collaborative`.
- `model/session_manager.py`: singleton account list and selected account. Retrieving existing accounts does not authenticate.

## Invariants

Keep dialogs and widget access on the GUI thread. Catch exceptions inside QThread workers. Apply immutable WorkerEvents only on the GUI thread and reject obsolete operation/collection scopes. Serialize browser sync/repair with batch sync/repair, block either UI from starting a concurrent mutation, capture the destination when queueing, and cancel/wait before closing active work. Before Repair Library or batch mutations, quiesce the player and wait asynchronously for Qt/FFmpeg file release; never play a Spotify URL or implicitly download a track. Account retrieval and profile getters must not trigger authentication/network calls. Refresh cached tokens before browser reauthorization and preserve OAuth state validation. The account list exists, but a user-facing Add account flow remains in the [backlog](../backlog.md).
